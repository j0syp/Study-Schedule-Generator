# Генератор навчального розкладу (Study Schedule Generator)

Цей проєкт є інтерактивним інструментом для студентів або людей, які займаються самоосвітою, для генерації навчального розкладу по днях.

## 🚀 Feasibility Summary

- **GitHub Pages Feasibility**: 100%. Проєкт повністю реалізовано на клієнті без потреби у бекенді чи базах даних.
- **Стек технологій**: Plain HTML, CSS, Vanilla JavaScript. Стек обрано для забезпечення максимальної простоти, уникнення зайвих залежностей та ідеальної сумісності зі статичним хостингом GitHub Pages.
- **Зберігання даних**: `localStorage`. Дані повністю ізольовані в браузері користувача.

## ✨ Можливості (Features)

- **Додавання предметів (CRUD)**: Додавайте предмети, визначайте необхідний час (від 15 до 600 хв), дедлайн та пріоритет (Низький, Середній, Високий).
- **Розумна генерація**: Алгоритм автоматично сортує предмети (спочатку ближчі дедлайни, потім високий пріоритет).
- **Бізнес-правила та пакування часу**:
  - Алгоритм орієнтується на заповнення ~240 хвилин (4 години) на один день.
  - Жодна безперервна сесія не перевищує 120 хвилин (алгоритм дробить довгі завдання).
  - Алгоритм уникає мікро-сесій (менше 30 хвилин) та не розриває короткі задачі без необхідності.
  - Наочні попередження: якщо день завантажено на 210-240 хв, з'являється порада (💡), а при >240 хв — попередження про перевантаження (⚠️).
- **Керування статусом**: Відмічайте згенеровані сесії як "Готово" (Completed) або "Пропуск" (Missed).
- **Фільтрація**: Переглядайте всі, невиконані, виконані або пропущені задачі.
- **Демо-дані**: У застосунку наявна кнопка "Відновити демо-дані", яка завантажить базові налаштування для демонстрації алгоритму.

## 🛠 Запуск локально

1. Клонуйте репозиторій.
2. Просто відкрийте файл `index.html` у вашому браузері або використовуйте `Live Server` у VSCode, якщо бажаєте бачити автоматичне оновлення.

## 🌐 Деплой на GitHub Pages

Застосунок містить налаштований GitHub Actions Workflow (`.github/workflows/deploy.yml`).
Для того, щоб опублікувати його:
1. Перейдіть у налаштування репозиторію **Settings > Pages**.
2. В розділі **Source** оберіть **GitHub Actions**.
3. Push/Merge у гілку `main` автоматично розгорне сайт.
